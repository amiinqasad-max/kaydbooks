# Assets Directory

This directory contains app assets like icons and splash screens.

For a complete Expo app, you would need:

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Web favicon

You can generate these assets using:
```bash
npx @expo/image-utils generate-icons ./path/to/your/icon.png
```

For now, the app will use default Expo assets.
