# 🌐 Language Support Dependencies

## Required Packages for Multilingual Support

Install these packages for internationalization:

```bash
# Core i18n packages
npm install react-i18next i18next

# AsyncStorage for language persistence (already installed)
# @react-native-async-storage/async-storage
```

## Package Information:
- **react-i18next**: React bindings for i18next internationalization framework
- **i18next**: Core internationalization framework
- **AsyncStorage**: Store selected language preference locally

## Features Enabled:
✅ Real-time language switching
✅ Persistent language preference
✅ Complete UI translation
✅ Professional Somali translations
✅ Instant updates across all screens

## Supported Languages:
- 🇺🇸 **English** (Default)
- 🇸🇴 **Somali** (Af-Soomaali)

After installation, the app will support complete language switching with professional translations!
